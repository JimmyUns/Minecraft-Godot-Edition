# Minecraft Godot Edition
 A custom godot .net replica of the game minecraft

 Includes:
 -Terrain generation
 -Working minecraft skin importation
 -Completed player controller (first and third-person)
 -Chunk system and blocks system that uses threading and performance saving
 -Fully working inventory system
 -Main Menu
